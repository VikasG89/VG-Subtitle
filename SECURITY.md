# Security Policy

## Supported Versions

We currently provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it responsibly.

**Do not open a public issue.** Instead, please email security@vg-subtitle.com (placeholder) or use the GitHub private vulnerability reporting feature if enabled.

We will acknowledge your report within 48 hours and provide a timeline for the fix. Please do not disclose the vulnerability publicly until a fix has been released.
