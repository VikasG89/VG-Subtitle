# Contributing to VG Subtitle & Audio AI Engine

Thank you for your interest in contributing to the VG Subtitle & Audio AI Engine! We welcome contributions from the community to help improve this library.

## How to Contribute

### Reporting Bugs
- Use the **Bug Report** template when opening an issue.
- Provide a clear description of the bug and steps to reproduce it.
- Include information about your Android version, device, and NDK version.

### Suggesting Enhancements
- Use the **Feature Request** template.
- Describe the proposed enhancement and why it would be useful.

### Pull Requests
1. Fork the repository.
2. Create a new branch for your feature or bug fix (`feature/my-new-feature` or `fix/my-bug-fix`).
3. Ensure your code follows the existing style and is well-documented (using KDoc for Kotlin and Doxygen for C++).
4. Write unit tests for any new functionality.
5. Submit a pull request to the `develop` branch.
6. All PRs must pass CI checks before being merged.

## Development Setup

- **Android Studio**: Latest stable version recommended.
- **NDK**: 28.2.13676358 or later.
- **CMake**: 3.22.1 or later.

## Code of Conduct
Please be respectful and professional in all interactions within this project.
